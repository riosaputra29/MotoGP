                        Izinkan akses file data

                        Pindai keamanan

                        Memeriksa pola alamat yang sering dipakai untuk penipuan dan penyebaran malware. Ini bukan antivirus: hasil bersih tidak menjamin aman. Pemeriksaan dasar berjalan di perangkat Anda dan tidak mengirim data apa pun.

                          Cek ke daftar ancaman Google (opsional)

                          Membandingkan link Anda dengan daftar situs malware dan phishing milik Google Safe Browsing. Perlu kunci API dari Google Cloud Console (aktifkan Safe Browsing API). Alamat link dikirim ke Google, dan kunci hanya disimpan di browser ini, tidak ikut cadangan.

                          Cek file

                          Pilih file (misalnya hasil unduhan) untuk melihat tanda mencurigakan dan menghitung hash SHA-256. File tidak diunggah ke mana pun. Hash bisa dicari di VirusTotal untuk melihat hasil puluhan mesin antivirus.

                            Cara pakai Live MotoGP

                            Fungsi

                            • Demo: simulasi balapan untuk latihan tampilan.
                            • Live resmi: mengambil data waktu langsung dari server timing MotoGP (posisi, selisih, waktu lap). Peta dihitung dari selisih waktu, jadi posisinya perkiraan dan bukan GPS.
                            • Tempel data / Feed JSON: cadangan bila data resmi tidak bisa dipakai.
                            • Layar siaran: tampilan penuh untuk ditangkap OBS.

                            Link yang diisi dan sumbernya

                            1. Data balapan: sudah terisi otomatis (api.motogp.pulselive.com, bagian timing-gateway/livetiming-lite), alamat yang dipakai situs motogp.com. Alamat ini tidak resmi didokumentasikan dan hanya berisi saat sesi berlangsung. Nomor, nama, dan tim pembalap dimuat otomatis dari data musim yang sama.
                            2. Kunci API YouTube: console.cloud.google.com, buat project, aktifkan YouTube Data API v3, lalu Credentials, Create credentials, API key. Gratis dengan kuota 10.000 unit per hari.
                            3. Live saya: YouTube Studio, menu Konten, tab Live, buka live Anda, lalu salin link (youtube.com/watch?v=... atau youtube.com/live/...). Dipakai untuk komentar penonton dan jumlah penonton.
                            4. Video ditonton (opsional): link YouTube lain yang boleh disematkan, tampil sebagai latar panggung. Siaran berbayar seperti VideoPass tidak bisa disematkan.

                            Cara siaran live reaction

                            1. Di YouTube Studio buat live dan ambil stream key, lalu masukkan ke OBS (Settings, Stream).
                            2. Di OBS tambahkan Window Capture atau Browser Source ke halaman ini, lalu klik Layar siaran.
                            3. Jika webcam tidak tampil di OBS, pakai Kotak kosong (OBS) dan taruh Video Capture Device OBS di atasnya.
                            4. Tempel link live Anda di panel Hubungkan YouTube agar komentar tampil, lalu klik komentar untuk memperbesarnya di layar.

                            Catatan hak cipta: menayangkan video siaran resmi MotoGP di live Anda berisiko diklaim atau di-strike. Format paling aman adalah tampilan data, kamera, dan suara Anda sendiri.
